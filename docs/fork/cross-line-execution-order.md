## 1. 排序依据（用户裁定，2026-09-16）

1. **验收先于新批次**：能力深化八篇专题（地面走廊、目标追踪、鞘翅导航、空中
   跟随、投射物瞄准、采掘、载具、红石）的验收收尾先完成，OV/TG 这一批才开工。
   这同时满足各计划的同步纪律——复用 CD 模块前，其常量与语义已通过验收固化
   （寻路在测试期多次被纠正是先例）。
2. **主线内顺序**：OV-1 → OV-2A → OV-3A → OV-3B → OV-3C → TG-0/TG-1 →
   free-play F0/F1 → TG-4（即 OV 计划 §11 完成门的展开）。
3. **调度唯一**：OV-3B/3C 交付"刺激 → 模型选择 → 一次自主动作"骨架；TG-0/1/2
   与 free-play F0/F1 在该骨架上扩展，不另建第二套刺激队列与调度。
4. **既定排后与阻塞**：multichannel 排后，OV/TG 均不依赖；RS 等材料解锁后
   独立走。

## 2. 阶段 0：验收收尾（当前唯一前线）

范围与判据以[验收清单](./capability-deepening-acceptance-checklist.md)为准，
此处只定先后。

**Step 0（一次性基线）**：两侧工作树分批提交，或至少把 AIRI 构建时间与双 jar
版本锚进清单 §6 登记表——后续每批证据都要按"构建 + 版本"取证，脏树会让基线
失去锚点。这是卫生步骤，不是闸门。

**A 类（可直接验收，人工配合型，按空档排；建议 L 先行）**：

1. CD-L 收尾：L-02、L-04..L-10；顺带复核 F-01（keepDistance 停车半径）。
   L 先行的理由：F-01/F-02 数据点都在 L 名下，且 L 的结局类型与生命周期语义
   是阶段 1 里 OV-3A 的直接输入。
2. CD-M（M-01..M-10）→ CD-B（B-01..B-10）→ CD-V（V-01..V-10）。
   若人工空档不足，A2–A4 可顺延进阶段 1 的空档，但不得晚于 free-play F4
   （拓展游玩）启动前。

**B 类（飞行线，先接线后验收）**：

1. B0/LR-0 接线批：flight/ 决策层接 live 驾驶、走廊接跟飞驱动、策略流按轮询；
   回归门槛 flight 77 / air-follow 33 / 移动 338 不回退，默认行为不变。
   并行 LR-1（纯函数估计器）与 LR-2（协同建议，真机部分可并入 B 场）。
   **进度（2026-09-18）**：接线四项全部完成，离线门槛通过（套件 842 通过 / 1 跳过）。
   LR-1 **接线完成**：D2 门在起飞评估与每拍起飞前生效，D4 闭合窗口每拍喂样本、连续两个
   不闭合窗口转有界安全降落，D5 回执字段就位。LR-2 仅建议模式与计数就绪，**消息发送链路
   未实施**；LR-3（能量管理）与 LR-4（走廊捷径、绕行系数进 D2）未实施。
   `escort` 非 `off` 仍需 `planner: 'on'` 且 `calibrated: true`，所以 E-01 通过前 escort 不会
   真正生效（宿主记 warn 并保持关闭）。E-01 采集脚本、运行手册与残差审计已就绪，
   真机采集 NOT-RUN（本轮连接前置全部不满足）。
   见[证据](./evidence/e01-flight-calibration-20260918/lr1-wiring-status-20260918.md)。
2. E-01 残差校准（10/20/40 tick）。清单硬规则：校准不通过，不启用 E2、E3
   与 F——这是后续一切飞行验收的前置。
3. B1 CD-E（E-02..E-10）与 B2 CD-F（FS-01..FS-09）**合并成一场飞行验收
   活动**：场地与天空旁观的人工成本一次覆盖两个对象；清单规则"验收中不改
   代码"，分开跑会重复搭场。
4. LR-3/LR-4（伴飞控制与走廊捷径，200/500 格场景）。

**C 类**：RS 等用户提供 Litematica/MaLiLib 1.21.1 产物与甘蔗机蓝图（基准
一例、变位两例、正常对照一例）后，按 RS-1..4 独立推进，与本阶段其他部分
无交叉。

**阶段完成门**：清单 §6 登记表全部回填（结果 + 证明范围），MODS 台账同步；
C 类允许带阻塞记录进入阶段 1。

## 4. 顺序裁定的理由（防止实施时被绕开）

1. **OV-5 不早于 B0/LR-0 与 E-01**：它的四个接入点（`runElytraMove` 起飞
   分支、空中跟随起飞评估、lifecycle 候选、输入交接）正是接线批要重接的 live
   路径；宏接在即将被替换的路径上等于白做，且其推进判据依赖 E-01 的物理档案。
2. **OV-3A 不早于 CD-L 收尾**：L-10（停止释放采样订阅）、L-08（迟到乱序）、
   L-07（轨迹重置）正是 watch 生命周期要继承的语义；阶段 0 先行已自动满足。
3. **调度唯一**：OV-3B/3C 之后，任何新线（TG、free-play、将来的 multichannel
   接入）都复用刺激队列、预算与运行权契约，禁止平行实现第二套。
4. **飞行验收合并**：一场人工配合覆盖 E/FS 两个对象；OV-5 因排在阶段 0 之后，
   自带一轮验收，可与 LR-3/4 真机时间相邻安排以复用人工，但判据分开记录。
