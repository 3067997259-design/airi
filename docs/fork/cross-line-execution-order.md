## 5. 顺序裁定的理由（防止实施时被绕开）

1. **OV-5 不早于 B0/LR-0 与 E-01**：它的四个接入点（`runElytraMove` 起飞分支、
   空中跟随起飞评估、lifecycle 候选、输入交接）正是接线批要重接的 live 路径；
   宏接在即将被替换的路径上等于白做，且其推进判据依赖 E-01 的物理档案。
   **本裁定已被遵守**：OV-5 在 B0 与 E-01 之后才落地。
2. **OV-3A 不早于 CD-L 收尾**：L-10（停止释放采样订阅）、L-08（迟到乱序）、
   L-07（轨迹重置）正是 watch 生命周期要继承的语义；阶段 0 先行已自动满足。
3. **调度唯一**：OV-3B/3C 之后，任何新线（TG、free-play、将来的 multichannel
   接入）都复用刺激队列、预算与运行权契约，禁止平行实现第二套。
4. **飞行验收合并**：一场人工配合覆盖 E/FS 两个对象；OV-5 剩余分支与 LR-3/4
   真机时间相邻安排以复用人工，但判据分开记录。2026-09-20 修订：E-02 及单程
   飞行先经飞行闭环 R0–R4 单独打通（不消耗人工配合、不消耗烟花），通过后再合并
   人工场次。这不改变"合并验收"的理由，只调整入口。
