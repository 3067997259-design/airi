# CD-V 载具真机验收（用户夹具，2026-09-17）

环境：客户端 0.2.21+（本轮含拉杆机关、滑行判定、下骑支撑、水路航点、骑乘校验修复）/ 服务端 0.2.16 / AIRI 应用为含全部宿主修复的构建。

## 本轮代码修复（全部带定向回归）

- **F-13 撤回**：0.2.18/0.2.19 怀疑"按键输入不驱动已乘船"是夹具封顶（乘员头部卡在石层）导致的假阳性；A/B 验证（去掉直喂输入的 0.2.21 同样可划）后已移除该改动。
- **F-14 修复**：船 `prepare_owned` 放置要从**读到的最近水面**选点（原为平视远处目标 → 不命中；俯角直落脚下地面 → 船体与方块重叠被服务端拒绝），并加 200ms 瞄准稳定。
- **F-15 修复**：客户端矿车轨道格读取 `y-0.5` 落到轨道**下方**一格 → 带电动力轨也报 `powered:false`；改用矿车自身格。
- **F-16 修复**：矿车旅行缺少骑乘校验 → 载具被毁时报 `launch_unavailable`；补 `vehicle_lost`（与船/马一致）。
- **F-17 修复**：矿车到站下骑未核对脚下支撑 → 在断点/大洞上方把玩家放下（玩家坠落）；改为不可读/无实心支撑即 `unsafe_dismount` 且不下骑。
- **F-18 修复**：矿车滑行时所在格已是普通轨，起步判定误报 `rail_not_powered`；改为"已观测到速度即视为已启动"。
- **F-19 新增能力**：矿车起步时可操作 4 格内的**拉杆机关**（区域读取找 lever → 看向 → `use_block` → 复读轨道）；船新增**水路航点跟随**（区域读取水域 → 4 邻 BFS → 沿水线可见最远点转向，输出较大时退回直线）。
- **F-20（新，能力缺口）**：服务端 `respawn` 工具存在于 schema，但桥方法 `player.respawn` 未实现（`unknown_method`），玩家死亡后无法由宿主复活（本次由用户手动点重生）。
- **F-21（新，能力缺陷；用户确认先记录）**：船的水路跟随只有前进/后退，缺左右划桨原地转向与倒船机动 → 斜段顶端 90° 直角无法通过（日志持续 `boat paddle turn unverified`）；`planRouteFollow` 是"沿水线可见最远点"的简化跟随。模组按键通道已支持 left/right，宿主规划未使用；后续用泛用性更好的路径规划 + 划桨转向实现。

## 夹具侧建议（供后续批次）

1. 水道第三段斜向折线每排偏移 1–2 格，船在 3 格宽下难以连续转向；建议加宽到 4–5 格或改为 45° 平滑阶梯。
2. B 线（站台→断点）的动力轨是平的，静止矿车不会自走；按 A 线的做法给一段**斜坡**（或其它推进设施）即可。
3. 分歧拉杆与弯轨形状的联动已验证正确（`south_west` ↔ `south_east`）。
