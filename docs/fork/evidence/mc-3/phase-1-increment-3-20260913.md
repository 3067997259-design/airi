## 发现与修复

1. **`interact.useItem` 是空气右键，不能开门**：mod 侧 `gm.useItem(...)`（`InteractHandlers.java:73`）不触发方块交互；`gm.useItemOn` 只在 `interact.placeBlock` 路径（同文件 :62）。`host-port.ts` 的 `useBlock` 改走 `place_block`（useItemOn）并加 NOTICE 记录移除条件；门房用例证明门被打开。
2. **挖掘必须"启动一次"**：桥的 survival break 是启动式动作（mod 注释"continues each tick"）；最初实现每 150ms 重发 `break_block`，导致进度反复重置（与 Phase 0 Baritone 观察同源）。改为：启动一次 + 每 1.2s 重试 + 轮询间持续锁定瞄准。石室用例三次稳定通过。
3. **规划偏好**：`allowBreak` 成本高（按硬度）时，A* 会先尝试跳爬再挖；开放场地中墙端会被绕行（测试台二格墙可绕，封闭石室不可绕），符合代价模型预期。
4. `swim-shore` 关闭了增量 2 的水坑缺口；正式默认 planner 翻为 `terrain`，`legacy` 保留为显式回退。
5. 调试轨迹仅在 `AIRI_TERRAIN_DEBUG` 环境变量设置时输出（`terrain:` 前缀）。
