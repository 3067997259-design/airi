## 增量 2：web 提取（链路代码完成）

- `shared/mc2/web.ts`：`detectInjectionSignals`（8 类标签：英/中"忽略指令"、system prompt、角色覆盖、调用工具、工具名、标 verified）、`extractWebLead`（标题/摘要/URL/fetchedAt/contentHash，纯字段，不接受页面文本附加任何行为）、`webKnowledgeOriginId`（`mc2:web:<fnv1a(url)>`）、`formatWebKnowledgeCard`（默认 `lead`；`crossedWith` → `candidate`；仅 `verified` 输入才 `verified`；注入嫌疑仅审计标注）。
- `knowledge.ts`：`knowledgeMarker` 支持 `lead`；`knowledgeTags` 支持 `kind:web` 与 `tier:lead`；探针 stale 降级修正（仅 `verified` 降 `candidate`，`lead` 保持自身等级）。
- 探针：`webLearn(urls, terms?)`（经 main `web_fetch`，SSRF 加固）、`webLearnText(text, url, terms?)`（保存的夹具文本走同一提取/写入路径，用于离线注入验收）。
- **单测 8 例 PASS**（含注入夹具：英/中指令 + 工具名 → 标签齐全；返回对象键集合固定；术语段落选择；标题回退；origin id 稳定/区分；卡片 lead/candidate/verified）。
