仅计算了穿越、伤害、预算，遗漏结束和场地边界。因此**不是整场通过**。

稳定，而 local-02 最后连续样本仍 `gliding=true`、`onGround=false`，
位置持续下降。不能把这类入水视为可靠收尾。
