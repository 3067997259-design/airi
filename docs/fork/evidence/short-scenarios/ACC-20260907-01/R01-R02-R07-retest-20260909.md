## Repair cause

The first R02 attempt exposed a product schema gap. The archive contained
four persisted AIRI error messages with `role: "error"`, but the restore
schema accepted only provider roles. The schema now accepts the documented
`ChatHistoryItem` error role, and a focused regression covers this case.

Focused restore tests: `3/3` passed. The historical R01 failure record remains
unchanged.
