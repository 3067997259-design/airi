# R0 失败复现记录（R0-20260920-01）

原始失败输出：`reproductions-failing.log`（vitest 4.1.11，25 测试 = 22 通过 + 3 失败）。三个复现均使用生产 `planLowRoute` 边界与脚本化世界，断言写的是 R1 契约。

## 1. 采样间薄墙漏检（执行文件 §4 第一反例）

- 场景：平面地表 y≤62；z=6 一格厚石墙（y63..100，全横向）；采样 step=4（z=4/8/12…）。
- **实际**：`planned`，waypoint z=96.5——路线笔直穿墙（断言失败：`expected 96.5 to be less than 6`）。
- **根因**：walk 只在采样步检查候选列自身；z=4 与 z=8 两列都有合法槽，两列之间的 z=6 墙体不可见。连通性检查 `hasAirAt(candidate)` 也只看候选列，不看两列之间的空间。
- **R1 契约**：路线不得穿墙——在墙前停止或拒绝；任何被接受的步进必须验证从上一点到该点的全部空间。

## 2. 斜向扩宽丢失目标层（执行文件 §4 第二反例，修订方案 §1 第三条）

- 场景：全平地表 y≤62；self (0,100,0)、goal (260,65,280)（斜向）；halfWidth 16。
- **实际**：`blocked`（断言失败：`expected 'blocked' to be 'planned'`）。
- **根因**：footprint 随横向扩宽增长 → `bottomOf` 分层预算把读窗口底部抬到 y≈101（topY−layers+1），目标锚定层 y=65/66 完全不在读取内 → 入口高度未读 = 未知 = 无候选 → 整体拒绝。请求格数仍在 32k 桥上限内（修订方案实测 31050 格），是预算分配策略问题，不是硬上限。
- **R1 契约**：横向扩宽时保留目标高度层；预算不足时返回具体原因，不允许裁掉目标层后报"无路"。

## 3. 完整路径未被表达（执行文件 §4 第三项，修订方案 §1 第二条）

- 场景：河道弯道——地表 y≤62，山脊 x -20..200 × z 110..130（y63..100 实心）；直线方位穿脊，唯一低空绕行在 x<-20；goal (165,65,345) 在脊外；span=400。
- **实际**：`planned` 但结果对象**没有 `path` 字段**（断言失败：`expected { status: 'planned', …(4) } to have property "path"`）。当前输出坍缩为最远 waypoint + 单一 bandY；waypoint 停在脊前（reached < 110），绕行路线完全丢失。
- **根因**：`elytra.ts`（修订方案 §1）丢弃规划结果的 `points`，只保留最远 waypoint 与 bandY；规划器本身也只输出逐 ahead 的列点而非连通路径。
- **R1 契约**：输出有序路径（或有序区域+入口序列），测试逐点验证：(a) 脊区间所有点 x < -20；(b) 每个点自身高度处是空气；(c) 终点落在目标空气区 8 格内。
